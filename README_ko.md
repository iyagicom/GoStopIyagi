# 고스톱이야기 (GoStopIyagi)

**PC 에서 즐기는 화투 — 고스톱(2~3인)과 삼봉. 똑똑한 AI 와 치거나, 같은 네트워크 친구와 LAN 대전.**

[English](README.md) · [한국어](README_ko.md)

## 왜 고스톱이야기인가

- **만만하지 않은 AI.** 수를 미리 읽어 보는 AI(MCTS)가 상대합니다. 혼자서도 제대로 긴장감 있는 판이 됩니다.
- **친구와 LAN 대전.** 같은 네트워크라면 한 명이 방을 열고 나머지가 들어오면 됩니다. 3인 고스톱도 됩니다.
- **제대로 된 규칙.** 광·열끗·띠·피, 약, 고/스톱, 흔들기 같은 손패약까지 점수를 정확히 셉니다.
- **고스톱만이 아닙니다.** 봉우리 패로 점수를 겨루는 **삼봉**도 들어 있습니다.
- **판이 살아 있습니다.** 남자·여자 목소리로 "고!", "뻑!", "따닥!", "광박!" 을 외쳐 줍니다.

## 게임

| 게임 | 인원 | AI 대전 | LAN 대전 |
|---|---|---|---|
| **고스톱** | 2~3인 | ✓ | ✓ |
| **삼봉** | 2인 | ✓ | ✓ |
